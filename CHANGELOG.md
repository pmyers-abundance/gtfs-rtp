# Changelog

## [0.1.0-draft] — 2026-04-26

### Initial public draft

- First public release of GTFS-RTP specification
- Eleven supplementary tables defined: rtp_routes, rtp_stop_context, rtp_products, rtp_packages, rtp_entitlements, rtp_trip_instances, rtp_capacity_snapshot, rtp_attribution_points, rtp_event_types, rtp_vehicles, rtp_trip_vehicle_assignment
- Schema derived from live production implementation (JRNY Transit, Australia)
- CC BY 4.0 license
- Open RFC process initiated — community feedback welcome
